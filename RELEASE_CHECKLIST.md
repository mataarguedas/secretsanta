# Release checklist — Secret Santa v1.0.0

Each PRD §13 acceptance criterion below is mapped to the automated tests that cover it and the manual step that confirms it in production. Tick the **Manual ✓** column during the release-gate walkthrough with 3 real people and phones (PROMPTS.md › Prompt 30 › Manual test 7). Then tag the release: `git tag v1.0.0 && git push origin v1.0.0`.

Test paths are relative to the repo root.
- **E2E** is `frontend/e2e/happy-path.spec.ts`. It runs in 4 projects (es/en × 390×844 / 1280×800) with an axe scan and design-rule check on every screen.
- **B:** means `backend/tests/`.

## Documented accessibility exception

PRD §9.4 documents a known contrast conflict: Coral Pop (#fa7864) with white or cream. It covers the white text on primary pills, the Banner strip, the active tab pill and the coral eyebrow labels. It's kept for now and flagged for product-owner review. The automated axe checks exempt contrast results that involve that exact color, and nothing else.

The terracotta secondary button used to fail contrast too (2.83:1). It now uses ink-black text on the terracotta outline (PRD §9.2).
